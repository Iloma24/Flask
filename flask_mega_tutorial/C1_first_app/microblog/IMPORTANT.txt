чтобы запустить данное приложение через терминал по файлу microblog.py - нужно перейти в папку с данным файлом и
выполнить в терминале следуующий код:
    вариант 1:
    export FLASK_APP=microblog.py  # установка переменной среды
    flask run  # запуск приложения

    вариант 2:
    flask --app microblog run
