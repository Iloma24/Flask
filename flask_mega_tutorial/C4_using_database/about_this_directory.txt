В данной главе получит развитие приложение из прошлой главы. Здесь будет показана взаимодействие приложения с базаой данных (БД)
Для работы с БД будут использованы два фласк-расширения - Flask-SQLAlchemy и Flask-Migrate.
    Flask-SQLAlchemy - это ORM, который позволяет приложениям управлять базой данных, используя высокоуровневые сущности,
такие как классы, объекты и методы, вместо таблиц и SQL. Работа ORM заключается в преобразовании высокоуровневых операций
в команды базы данных. SQLAlchemy это ORM не для одной, а для многих реляционных баз данных. SQLAlchemy поддерживает длинный
список движков баз данных, включая популярные MySQL, PostgreSQL и SQLite. Это чрезвычайно мощный инструмент, потому что
вы можете выполнять свою разработку, используя простую базу данных SQLite, для которой не требуется сервер, а затем, когда
придет время развертывать приложение на производственном сервере, вы сможете выбрать более надежный сервер MySQL или
PostgreSQL без необходимости изменять свое приложение. Установка - pip install flask-sqlalchemy
    Flask-Migrate - это расширение представляет собой оболочку Flask для Alembic, платформы миграции баз данных для
SQLAlchemy. Миграция БД - перенос данных из моделей в таблицу БД. Работа с миграциями баз данных добавляет
немного работы для запуска базы данных, но это небольшая плата за надежный способ внесения изменений в вашу базу данных
в будущем. Установка - pip install flask-migrate
    Есть два способа создать миграцию базы данных: вручную или автоматически. Чтобы сгенерировать миграцию автоматически,
Alembic сравнивает схему базы данных, определенную моделями баз данных, с фактической схемой базы данных, используемой в
данный момент в базе данных. Затем скрипт миграции заполняется изменениями, необходимыми для приведения схемы базы данных
в соответствие с моделями приложений.
