Эта глава будет посвящена добавлению страниц профиля пользователя в приложение. Страница профиля пользователя - это
страница, на которой представлена информация о пользователе, часто с информацией, введенной самими пользователями. Здесь
показано, как динамически создавать страницы профиля для всех пользователей. Затем добавлен небольшой редактор профиля,
который пользователи смогут использовать для ввода своей информации.
